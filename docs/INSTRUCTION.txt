# StudHub Launcher 0.4.7 — сборка 1.0.2

Minecraft 1.21.1 · NeoForge 21.1.250 · Java 21.
Сервер: studhub.sigma.band. Для автоподключения используется 148.253.208.254:25589.

## Первый запуск

1. Установите StudHubLauncher-0.4.7-Setup.exe. В установщик уже включены 48 JAR-файлов из предоставленной сборки.
2. Откройте «Профиль», введите ник и нажмите «Сохранить ник». Microsoft и Telegram не нужны.
3. Нажмите «ИГРАТЬ». Лаунчер проверит встроенный модпак, установит Java 21, Minecraft 1.21.1 и NeoForge 21.1.250 и запустит игру. Для игровых компонентов нужен Интернет.
4. Если установленная сборка содержит несовместимые пользовательские моды, переместите указанные файлы за пределы mods и повторите запуск. Предустановленные моды самостоятельно добавлять не требуется.

Сервер должен разрешать вход по нику без Microsoft. Настройки сервера лаунчер не меняет. Смена ника или его регистра меняет UUID, поэтому сервер может создать новый профиль/инвентарь.

| Папка mods | Открывает папку для ваших дополнительных модов. |

| Память и папки | Переключатель памяти сохраняется сразу, ползунок — при отпускании, пути — при выходе из поля или выборе папки. |

Автоматическая проверка модпака выполняется при открытии клиента, если включены обновления, и перед запуском игры. Встроенная сборка обновляется с новой версией установщика. Динамические обновления через Интернет требуют CDN; адрес CDN пока не задан.

## RAM

Это максимум оперативной памяти, которую может использовать Minecraft. По умолчанию выбран автоматический режим: примерно половина памяти компьютера, минимум 2 и максимум 8 ГБ. Например, компьютер с 8 ГБ → лимит игры 4 ГБ; с 16 ГБ → 8 ГБ. Память не обязательно занимается вся сразу.

## Обнаруженная проблема в исходном архиве

У JEI в метаданных указан диапазон Minecraft "[1.21, 1.21.1)", исключающий 1.21.1. JAR сохранён без изменений. Если NeoForge остановится на этом конфликте, нужен корректный JEI из рабочей клиентской сборки. Подробнее — PACK-AUDIT.md.

## Владелец

Вводит ник так же, как игрок. OP/whitelist/права назначаются на сервере. Telegram-бот работает отдельно. Microsoft Client ID не используется.

Сборка, восстановление файлов и desktop-интерфейс проверяются отдельно от настоящего запуска на Windows и подключения к серверу. См. TESTED.md.

## Google Drive

Папка актуальной сборки: https://drive.google.com/drive/folders/1iGRUgwkS9e6HHqZ9ItJ50msGRBld9lGF . Проверка выполняется при открытии лаунчера, перед запуском игры и по кнопке «Проверить Drive» в разделе «Сборка». Она сравнивает ID, имя, размер и дату изменения файлов, сообщает о добавлениях, изменениях и удалениях. Исходная точка сравнения — архив 1.0.2 из этой папки на момент первоначальной проверки в версии 0.4.5. Последующий список сохраняется на компьютере.

Это проверка наличия обновлений. Новые архивы автоматически не скачиваются и не устанавливаются; загрузить их можно через «Открыть папку». Для автоматической установки продолжает использоваться встроенная сборка 1.0.2 либо настроенный подписанный CDN. Проверка охватывает файлы и папки в корне, без содержимого вложенных папок.

Папка должна оставаться общедоступной. Используется публичная веб-страница Google Drive без входа: если Google изменит формат, закроет доступ или произойдёт ошибка сети, интерфейс покажет «не проверено», сохранив предыдущий список. Папки от 50 файлов не считаются полностью проверенными. Ошибка Drive не препятствует запуску встроенной сборки.

## Оформление и баннер

Статус сервера и версия в боковой панели используют увеличенный пиксельный шрифт Monocraft с кириллицей. Надпись STUDHUB — читаемый жирный Manrope. Баннер включает три локальных пейзажа Minecraft и меняется каждые пять секунд. Стрелки и точки позволяют выбрать изображение вручную, кнопка паузы останавливает смену. При наведении, фокусе на элементах баннера, скрытом окне или предпочтении уменьшенной анимации перелистывание приостанавливается.

Нижний блок настроек с автоподключением, обновлениями при старте, отдельными кнопками сохранения/логов и импортом подключения удалён из интерфейса. Память и пути сохраняются автоматически. Журнал доступен по значку терминала вверху.

## Версия 0.4.7

Карточка «Сервер StudHub» удалена из профиля. Общий онлайн в главном окне обновляется автоматически каждые 15 секунд. Число людей именно на спавне требует подключения отдельного серверного счётчика. Автоматическая установка новой версии лаунчера реализована для Windows; источник подписанных выпусков пока не задан владельцем. Настройка — docs/AUTO-UPDATES.md в исходниках.
