# Проверено для StudHub Launcher 0.4.8

- TypeScript/Vite: успешная сборка.
- 26 Rust-тестов прошли в 0.4.7, включая реальную распаковку 48 файлов, SHA-256 всех модов, восстановление повреждённого JAR, сохранение дополнительных пользовательских файлов, повреждённый встроенный архив, UUID/ник, память, загрузчик и управляемое обновление.
- Сетевой Rust-тест ядра в 0.4.5: прочитана настоящая публичная папка Google Drive, найден архив сборки 1.0.2.
- Тесты Drive: новые/изменённые/удалённые файлы, переименование, неизвестная страница, неполный список.
- 2 frontend-теста и 2 теста генераторов подписанного manifest и выпуска лаунчера.
- 25 проверок в настоящем Tauri/WebKitGTK-окне Linux: автоматическая установка сборки 1.0.2, все 48 управляемых JAR, чтение библиотек Kotlin, отсутствие ложных конфликтов контейнеров, ремонт повреждённого мода через кнопку без CDN, сохранение ника/RAM, отклонение старых Microsoft/Telegram-команд, папка mods, журнал, навигация, окно 960×660, читаемая надпись, увеличенные статус/версия шрифтом Monocraft, иконки Minecraft, настоящая проверка Google Drive через Rust IPC, три локальных пейзажа и автоматическая/ручная смена/пауза, удаление нижнего блока настроек, автосохранение RAM без применения чернового ника, удалённая карточка сервера в профиле, фоновый Minecraft status TCP со сменой онлайна с 5 до 9 на локальном тестовом сервере.
- Windows x64 exe: компиляция с tauri/custom-protocol успешна.
- NSIS-установщик: включает exe, ресурсы сборки, прозрачную иконку, инструкцию и загрузчик WebView2.

В архиве сохранены исходные JAR без изменений. Найдено исключение Minecraft 1.21.1 в объявленном диапазоне JEI. Подробности — PACK-AUDIT.md.

Не проверено: запуск этой версии на настоящем Windows, полная установка NeoForge 21.1.250 в этой версии, запуск Minecraft с указанным набором модов до главного меню, соединение с StudHub и фактические настройки входа на сервере. Тесты файлов не подтверждают совместимость модов во время исполнения.

Журналы предыдущих версий в evidence являются историческими; текущие результаты помечены 0.4.7.

Для автообновления проверены контракт NSIS, формирование скрипта ожидания/установки/перезапуска, подпись выпуска и точный SHA-256 установщика. Для спавна — числовой ответ, обязательное время подсчёта, отказ от устаревшего/некорректного ответа. Автоустановка на настоящем Windows, публикация HTTPS-источника выпусков и серверный мод подсчёта спавна не проверены/не развёрнуты.

0.4.8: дополнительно проверяются отсутствие карточки обновлений/ненужных подписей, увеличение StudHub/Обнаружен и новый запрос Google Drive при нажатии ИГРАТЬ. Сценарий запуска использует заведомо отсутствующий Java-путь, поэтому тест не запускает Minecraft; проверяет именно проверку Drive до запуска. Карусель проверяется при наведении и фокусе, включая паузу и возобновление.

macOS DMG не собран, macos.yml подготовлен, но не запущен. Выбор ярлыка: NSIS-компиляция и проверка логики сохранения выбора; фактический диалог на Windows не запущен.
