# StudHub Launcher 0.4.9 — обязательная проверка обновлений

При открытии появляется блокирующий экран до ответа GitHub Releases.

Rust-команда `play` делает **новый сетевой запрос** к GitHub перед запуском игры. Только статус `current` разрешает запуск. Новая версия, отсутствие релиза, таймаут, HTTP-ошибка и отсутствие сети блокируют запуск.

Опубликуйте v0.4.9 с EXE в Releases. В противном случае версия 0.4.9 не сможет пройти проверку (текущий релиз v0.4.8).

GitHub Release открывается только по проверенному URL; автоматическая установка неподписанного EXE не выполняется.

Это не защищает от изменения кода или подмены исполняемого файла пользователем на его собственном компьютере. Для принудительной политики на сервере нужна серверная проверка.
