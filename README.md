# StudHub Launcher 0.4.8

Нативный клиент Tauri 2 + React + Rust. Вход по нику. Minecraft 1.21.1, NeoForge 21.1.250. Включена сборка пользователя 1.0.2 (48 JAR).

Инструкция: docs/PLAYER-GUIDE.md. Проверка состава и проблема метаданных JEI: docs/PACK-AUDIT.md.

Сборка: npm ci; npm run tauri build. В конфигурации Tauri указан архив resources/studhub-pack-1.0.2.zip. Для переносимого запуска архив должен быть рядом с exe в resources/. Используйте установщик, который включает этот файл. CI: .github/workflows/build.yml.


0.4.8: удалён нижний блок настроек; память/пути сохраняются автоматически. Статус сервера и версия крупнее, шрифт Monocraft с кириллицей; надпись StudHub — читаемый Manrope. Баннер: три локальных изображения, автосмена через пять секунд, ручной выбор и пауза.

0.4.8: карточка сервера удалена из профиля, общий онлайн опрашивается каждые 15 секунд. Автообновление Windows через подписанный источник и NSIS; источник пока не задан. Поддержан отдельный HTTPS-счётчик спавна; серверный мод требуется отдельно. Инструкция и публикация выпуска: docs/AUTO-UPDATES.md, tools/launcher-release.mjs.

## Изменения 0.4.8

Карусель продолжает перелистывание при наведении и фокусе на кнопках; остановка только кнопкой паузы или при скрытом окне. Удалена домашняя карточка обновлений и подписи общего онлайна/управляемых модов. Источник и состояние модов показаны крупным жирным Manrope. Drive автоматически проверяется перед запуском игры. В Windows-установщике отдельная галка ярлыка с сохранением выбора при последующих обновлениях, отдельная инструкция больше не устанавливается.

macOS: подготовлен universal build (Intel + Apple Silicon), tauri.macos.conf.json и ручной GitHub Actions workflow macos.yml. Готовый DMG ещё не собран: в текущей среде нет macOS runner, Apple SDK и учётной записи GitHub. Ad-hoc подпись не заменяет Apple Developer ID/notarization. Проверки Mac, Java и самой игры на Mac не выполнены.

## Обновления через GitHub Releases

Проверка актуальной версии при запуске и каждые 30 минут подключена к публичному GitHub API. Новые стабильные версии открываются через официальный GitHub Release; неподписанные исполняемые файлы не запускаются автоматически. Подробнее: [docs/GITHUB-UPDATES.md](docs/GITHUB-UPDATES.md).
